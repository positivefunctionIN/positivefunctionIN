### 🩻 Featured: Medical Imaging Work

**[Pneumonia Detection — CNN, Attention & Interpretability]([link-to-repo](https://github.com/positivefunctionIN/Medical_Imaging_using_CNN))**
Compared three architectures for chest X-ray pneumonia classification — a custom CNN, a CBAM attention-augmented hybrid, and ResNet50 transfer learning — then went further with a PyTorch/Captum interpretability layer (Integrated Gradients, Grad-CAM, Saliency Maps) to visualize *what* the model is looking at.
`PyTorch` `Captum` `Grad-CAM` `CBAM` `Transfer Learning`

**[3D Spleen Segmentation — MONAI]([link-to-repo](https://github.com/positivefunctionIN/spleen_segmentation))**
Working through Project MONAI's official tutorials, applying medical imaging segmentation pipelines to 3D volumetric data.
`MONAI` `3D Segmentation` `Medical Imaging`

**[Plant Disease Detection — MobileNetV2]([link-to-repo](https://github.com/positivefunctionIN/Plant_Leaf_Disease_Prediction_2.0))**
My first deep learning project — lightweight CNN classification on the PlantVillage dataset, ~90% validation accuracy. Not medical, but where the CV fundamentals started.
`MobileNetV2` `Transfer Learning`
